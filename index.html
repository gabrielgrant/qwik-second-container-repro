Qwik 2.0.0-rc.4: second client container loses synchronous event dispatch

The same component is rendered twice with render() from @qwik.dev/core, into two sibling divs. The child button's plain-function onClick$ calls event.stopPropagation(), which must prevent the parent's handler from running. Each run clicks the child button once and records every handler call plus a native bubble listener on the parent.

Expected log (and what 2.0.0-beta.36 produces for BOTH containers): ["child-handler"]. On 2.0.0-rc.4 the second container logs ["parent-native-bubble", "child-handler", "parent-handler"] — handlers ran asynchronously after native propagation finished, so stopPropagation (and conditional preventDefault) can no longer work.
